# InkCanvasForPDF

一个高性能 PDF 墨迹书写应用

###### **开发中，不建议在生产环境使用**

### ✨ 亮点

##### 时间笔锋

仿希沃系时间笔锋，每个墨迹点在抬笔钱缓慢生长至对应粗细，若抬笔则停止生长，从而达到笔锋效果

##### 丰富图形支持

支持丰富图形，包括直线、箭头、圆、正方形、立体图形、函数、平面直角坐标系等

##### 墨迹纠正

基于WinRT墨迹识别，停顿时或抬笔时自动将手写墨迹转化为标准图形

##### 高性能

基于性能强劲的WPF与PDFium开发，更快的打开速度与更流畅的体验

##### 现代外观

本应用使用iNKORE.UI.WPF.Modern库，遵循Fluent Design 2设计规范
